# 统一桌宠

[English](README.md) · **简体中文**

五个原生 macOS 桌宠，共用一套交互。每个应用保留自己的入口、身份和已保存的设置。

## 操作

| 操作 | 行为 |
|---|---|
| 左键单击 | 等待0.3秒，没有第二下才打开原生菜单。 |
| 选择一项 | 播放一次；选择猫时，当前窗口立即换成所选猫并播放动作和声音。 |
| 双击 | 猫播放当前角色的素材；真人桌宠和奶龙随机播放一段语音。 |
| 拖动 | 只移动，不触发播放。 |
| 右键 | 打开设置：音量、静音、大小、显示范围、角色选项、恢复位置和关闭。 |

左右键共用同一个原生 `NSMenu` 入口，不再自绘面板、菜单行或灰色按钮块。菜单采用系统紧凑尺寸；屏幕确实放不下全部条目时，由 AppKit 处理溢出，不伪造多列系统菜单。

第二次按下发生在 **0.3秒内**，就取消待弹菜单，松开时播放一次，不闪菜单。拖动、右键及窗口或生命周期变化都会取消等待。这项设置不修改系统鼠标偏好，也不采样全局按键或接管原生菜单输入。

同一只桌宠不叠音；停止会取消等待中的回复。静音保留原音量，猫静音时仍有动作。设置会保存；测试保持静音，并与正常用户偏好隔离。

**跨猫随机仅由左键菜单的“随机播放”触发**，不是双击猫的行为。

真人桌宠只需设置“自动接话”开关和“接谁的话”。开启后会接所选角色的话，包括它的自动回复；**最多连续接两句**，防止循环不停，不需要另开接龙开关。总开关只控制本只是否接话，不影响其手动播放被其他桌宠听到。修改来源、手动播放或停止都会取消等待中的回复。

接话时间沿用原作者的计算：补偿下一句开头的静音，提前 **0.3秒**叠入前一句尾音；SunPet 和好事桌宠在 **hop 1 时提前0.2秒**，最小调度延迟为0.02秒。不额外添加随机停顿或收尾缓冲。仍会重叠前一句的尾音；多条独立的手动对话并未做全局排队。

开启自动接话后，默认来源设置形成 **薄肌 → 峰哥（好事） → 孙宇晨 → 停**。顺序来自可修改的来源选择，不是写死的角色路线。同一句若被多只桌宠同时勾选，仍可能一起接；想按顺序说，就让每只只选自己的上一位。自己正在说话时可以先排下一句，但轮到时若仍在播放，就跳过，不打断当前声音。

## 应用

| 构建目标 | 应用 | 内容 |
|---|---|---|
| `sun` | SunPet／太对了 | 28段原声；可选自动接话和机身摇晃输入。 |
| `shaolan` | 薄肌桌宠 | 37段原声；全量手动随机，可选短句接话。 |
| `goodthing` | 好事桌宠 | 11段原声，有明确的自动接话开关。 |
| `nailong` | 奶龙桌宠 | 6段原声，支持1–3只；不叠音，不再长按循环大笑。 |
| `cats` | 猫梗桌宠 | 10种猫梗，每个角色对应一个完整音画项，支持1–3个窗口。 |

猫保留原片动作，包括 Happy 跳舞和 Oiiai 旋转，而不是晃动静态图。透明帧使用固定画布，以音频播放器的实际时间同步；每个活动窗口的帧缓存上限为 **32 MiB**。播放结束或停止后恢复待机图，释放动画工作。

猫下方不显示“原片音轨”等素材说明，但真正的播放错误仍会提示。应用不需要网页、摄像头、麦克风或辅助功能权限，也不依赖外部网络服务。

## 构建

需要 **Apple Silicon、macOS 14或更新版本，以及 Xcode Command Line Tools**。运行时代码使用 Swift、AppKit 和 AVFoundation；SunPet 还保留了原有的 IOKit／Network 机身摇晃辅助模块。不需要额外的包管理器运行时框架。

先将有权使用的素材放入被 Git 忽略的 `.local-media/`，具体见[素材说明](docs/MEDIA.md)。**公开仓库不含第三方素材，缺少所需资源时无法构建。** 构建会明确报错，不会自动下载或生成替代素材。

```sh
./build.sh cats       # 也可选 sun / shaolan / goodthing / nailong
./build.sh all
```

产物位于 `build/<应用名>.app`。脚本会执行临时签名、严格签名验证和隔离的静音自测，但不会安装应用，也不会启动正常模式。

原生窗口和动画冒烟测试使用实际应用文件名：

```sh
"build/奶龙桌宠.app/Contents/MacOS/NailongPet" --ui-smoke-test
"build/猫梗桌宠.app/Contents/MacOS/CatMemePets" --ui-smoke-test --screenshot "$PWD/build/cats-ui.png"
python3 scripts/check-public-tree.py
```

动画准备使用已有的 FFmpeg、FFprobe 和 Pillow。这些是离线素材处理工具，不是应用运行时依赖。

## 仓库结构

- `Shared/`：五个应用的左右键共用的原生菜单入口。
- `Shared/Human/`：三个真人桌宠共用的接话通道、协议和配置；各目标仅保留很小的停止测试适配器。
- `Shared/Native/`：猫与奶龙共用的拖拽判断和随机逻辑。
- `Apps/Human/targets/`：固定版本的 SunPet、ShaolanPet、FengGe 源码，上游声明和本地改造。
- `Apps/Cats/`、`Apps/Nailong/`：原生应用和隔离测试。
- `scripts/`：本机素材处理及公开源码检查。
- `Licenses/`、`CREDITS.md`：作者署名和权限边界。
- `.local-media/`、`.local-config/`、`.local-evidence/`、`build/`：仅本机使用的忽略目录，不是公开产物。

实际验证和安装记录统一保存在[任务状态账](docs/task-status.md)。应用保留原有 Bundle ID，迁移时不重置用户设置。此前的同级仓库是历史副本，不再作为并行维护的实现。

## 本机安装

替换已验证的应用包之前，先退出对应桌宠，保留 Bundle ID 和偏好设置。五个应用使用独立的偏好域；不要删除其他桌宠，也不要为安装而降低系统签名或安全设置。

应用入口保留在 `/Applications`。不要同时运行旧可执行文件和新应用包。对于支持多只桌宠的应用，“关闭本只”与“退出整个应用”是不同操作。

卸载时先退出，再仅移除目标应用。构建验证结束后可以清理可重建的 `build/`；原始下载包和必要素材不是可随意删除的缓存。
